# Security Policy

## Supported Versions

This project is pre-1.0. Security fixes target the latest active version line.

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| 0.1.x | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Send reports to:

```text
lavyoung1325@outlook.com
```

Please include:

- Affected artifact and version.
- What the issue is and why it matters.
- Reproduction steps when possible.
- Any known workaround.

Reports are reviewed before public disclosure.
